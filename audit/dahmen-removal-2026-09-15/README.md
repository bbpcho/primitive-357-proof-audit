# Withdrawal of the Dahmen–Siksek paper copies

On 15 September 2026 the author requested removal of the Dahmen–Siksek working paper from earlier public distributions because redistribution permission had not been obtained.

The paper was a 235,180-byte PDF named `primary/dahmen-siksek/GFE357.pdf` inside the local-algebra evidence TAR, nested in the full source/data release and the first-submission companion. Both affected public assets have been withdrawn:

- `PRIMITIVE_357_FIRST_SUBMISSION_COMPANION_V1.zip`, GitHub asset565450862, release `first-submission-2026-09-15.1`.
- `PRIMITIVE_357_VERIFIED_RELEASE_2026-09-14_V1.zip`, GitHub asset563394734, release `verified-2026-09-14.1`.

Their original download URLs and API endpoints returned404 in an independent unauthenticated check. The release pages now explain the withdrawal; the original checksum ledgers remain as provenance. Existing private local archives were not overwritten or republished.

The remaining public p=5 and rank packages match their recorded digests and do not contain the identified PDF. All public Git refs were matched to the complete local history and its reachable blobs; the PDF was not in Git history. The automatically generated Git source archives therefore do not require a history rewrite. The scan and removal verification records are included here.

This withdrawal removes the identified public GitHub downloads. It does not purport to revoke copies previously downloaded elsewhere. Citations to Dahmen–Siksek remain in the manuscript. The current manuscript, its small source ZIP, the mathematical inputs and the historical replay claims have not been changed by this distribution action.

A complete replacement companion has not yet been published. Removing a member changes the nested archive's identity and its verification contract, so a replacement must have a new filename, checksum and accurately stated replay coverage. Other third-party material, including PVT inputs, remains a separate permissions/repackaging matter. The paper's Section8.5 identifies the historical archives; their current availability is governed by the withdrawal notices.

`WITHDRAWAL.json` binds the two former assets and the removed PDF. `PUBLIC_REMOVAL_VERIFICATION.json` records the requests and status codes. `PUBLIC_COPY_SCAN.json` and the scan script document the retained-archive and Git-history checks. No email has been sent and no arXiv submission has been made.
